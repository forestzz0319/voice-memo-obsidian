# 字幕ページ（caption.html）設計

- 作成日: 2026-10-09
- 状態: 設計承認済み

## 目的

診察室のPCで、レントゲンや薬の説明をするときに、先生が話した内容を大きな文字の字幕として
画面に表示し、耳の不自由な患者さんに読んでもらう。医療用語の誤変換補正とフィラー除去はClaudeで行う。

## 前提

- 先生→患者さんの一方向のみ。患者さんの返事は口頭・筆談など（アプリでは扱わない）。
- PCの画面1枚を一緒に見る。PCのChromeで使用。
- 説明の場面だけで使い、氏名など個人を特定する情報は口にしない運用（内容はClaude APIに送信される）。
- 会話の記録・保存はしない（画面表示のみ。クリアで消える）。

## 構成

既存の voice-memo-obsidian（GitHub Pages）に1ページ追加する。インストール不要、URLを開くだけ。
同じ配信元なので、メモアプリで保存した設定（APIキー・モデル・ユーザー辞書）をそのまま使う。

```
caption.html / caption.css / caption.js   画面
caption-prompt.js                         補正用プロンプト（純粋関数）
captioner.js                              1文ごとのClaude補正（並列・失敗時は原文のまま）
speech.js                                 continuous オプションを追加（既定 false。PCの字幕では true）
```

## 表示の流れ

1. 「開始」で音声認識（`ja-JP`, continuous, interim）。最大時間なし。「停止」まで続ける。
2. 途中結果は最下行に薄い色で即表示。
3. 1文確定 → 黒字の新しい行として追加し、同時に `captioner.add()` でClaudeへ。
4. 補正結果が返ったら、その行の文を差し替える（差し替え中の印は控えめに）。
5. 新しい行が追加されたら、最下部へ自動スクロール。

## Claude による補正

- 送るもの: 補正対象の1文＋直前の行（最大3行、補正済みがあればそれ）を文脈として。ユーザー辞書をシステムプロンプトに含める。
- 指示: 医療用語の誤変換補正、フィラー・言い直しの除去、句読点の付与。意味を変えない・言い換えない・要約しない・付け足さない。補正後の1文だけを出力。
- モデル/設定: 設定のモデル（既定 claude-opus-5-5）、effort low、`fallbacks: "default"`、max_tokens 1000、非ストリーミング。
- 安全策: 出力が空、または入力より極端に長い（2倍＋20文字超）場合は原文のまま。APIエラー・拒否も原文のまま表示を続ける。
- 文ごとに独立した呼び出しなので並列可。結果は行IDで対応づける。

## 画面

- 字幕エリアが画面のほぼ全体。文字サイズは「大」(32px)・「特大」(48px) を切替（ブラウザに記憶）。
- 上部の細いバー: 開始/停止、文字サイズ、クリア、⚙設定（APIキー・モデル・辞書）。
- 開始中は画面のスリープを防ぐ（Wake Lock API、失敗しても無視）。
- 「話した内容はClaude APIに送信されます。氏名などは話さないでください」を小さく表示。

## エラー処理

| 状況 | 動作 |
|---|---|
| 音声認識非対応 | メッセージ表示、開始ボタン無効 |
| マイク拒否 | メッセージ表示、停止状態へ |
| APIキー未設定 | 字幕は原文のまま表示し、上部に「補正なし（APIキー未設定）」 |
| API失敗・拒否 | その行は原文のまま。上部に最後のエラーを小さく表示 |

## テスト

- `caption-prompt.js`: 辞書あり/なし、文脈の組み立て。
- `captioner.js`: 偽SDKで、結果の差し替え・文脈の受け渡し・失敗時の原文維持・極端に長い出力の拒否・APIキー未設定。
- `speech.js`: continuous オプション。
- 画面: ヘッドレスChromeで偽の音声認識と偽API応答による通し確認。実際のマイクと補正品質は診察室PCで確認。
