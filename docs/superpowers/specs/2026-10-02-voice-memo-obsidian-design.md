# 音声メモ → Obsidian 整形アプリ（voice-memo-obsidian）設計

- 作成日: 2026-10-02
- 状態: 設計承認済み、実装計画待ち

## 目的

Androidスマホで短い音声メモ（〜1分程度のアイデア・考えごと）を話すと、
フィラー（「えー」「あのー」等）や言い直しを除き、医療用語の誤変換を文脈から補正し、
そのままObsidianに登録できる体裁（frontmatter・タイトル・タグ付きMarkdown）に
リアルタイムで整形する。ボタン1つでObsidianアプリに新規ノートとして作成する。

## 前提・制約

- 端末: Android（Chrome）。iPhone対応はスコープ外。
- 利用者: 院長本人のみ。配布しない。
- 内容: 自分用のアイデア・考えごと（note/YouTubeネタ、診療の気づき、勉強メモ）。
  **患者の個人情報は含めない運用**（内容はClaude APIに送信されるため）。画面と設定画面にその旨を表示する。
- Obsidian: スマホにObsidianアプリがあり、保管庫 `forest` がObsidian Syncで同期済み。
- サーバーは持たない。APIキーは端末のlocalStorageにのみ保存する。

## 全体構成

ビルド不要の静的PWA。GitHub Pagesで公開（マイク使用にHTTPSが必要なため）。
公開するのはコードのみで、APIキー等の秘密情報はリポジトリに含めない。

```
02_アプリ開発/voice-memo-obsidian/
  index.html      画面（メイン＋設定）
  style.css
  app.js          画面の状態管理と各モジュールの結線
  speech.js       音声認識（Web Speech API）
  formatter.js    Claude呼び出し（ストリーミング・デバウンス・キャンセル）
  prompt.js       整形プロンプト組み立て（純粋関数）
  note.js         出力の解析とノートMarkdown組み立て（純粋関数）
  obsidian.js     obsidian:// URL生成・ファイル名サニタイズ（純粋関数）
  settings.js     設定の読み書き（localStorage）
  manifest.json / sw.js / icons/   PWA
  test/           node --test による単体テスト
```

### データの流れ

1. 🎤押下 → `speech.js` が `SpeechRecognition`（`lang: ja-JP`, `continuous: true`, `interimResults: true`）を開始。
2. 途中結果（interim）は原文欄に薄く表示。確定（final）するたびに原文バッファへ追記し、`formatter` に通知。
3. `formatter.js` は最後の確定から約1秒待って（デバウンス）、**原文全体**を送信。
   実行中のリクエストがあれば `AbortController` で中断し、新しいものだけを生かす。
4. ストリーミングで届いたテキストを `note.js` で逐次解析し、プレビュー欄に表示。
5. 認識が無音などで自動停止した場合、もう一度🎤を押すと同じメモに追記される。
6. 「Obsidianへ」押下 → `note.js` が最終ノートを組み立て → `obsidian.js` がURL生成 → `location.href` で起動。

### プレビュー手動編集時の扱い

- プレビュー欄をユーザーが編集したら「手動編集モード」にし、以降の自動整形で上書きしない。
- その状態では「再整形」ボタンを表示。押すと手動編集を破棄して原文から再整形する（確認ダイアログあり）。
- 原文欄も手で編集できる。原文を編集した場合は、デバウンス後に再整形する（手動編集モードでなければ）。

## Claude 呼び出し

- 公式SDK `@anthropic-ai/sdk` をCDN（jsDelivrのESM版）から読み込み、`dangerouslyAllowBrowser: true` で利用（個人専用のためキーを端末に置く方針）。
- モデル: 標準は `claude-opus-5-5`、`output_config.effort: "low"`。設定で `claude-sonnet-5-5` に切替可。
- `messages.stream()` を使い、テキストの差分を受け取って表示する。`max_tokens` は 4000。
- 拒否時の振り替え（`fallbacks: "default"` ＋ ベータヘッダ `server-side-fallback-2026-07-01`）を有効にする。
  `stop_reason` が `refusal` のままなら原文を残してエラー表示。
- プロンプトキャッシュは使わない（システムプロンプトが短く、最低キャッシュ長に届かないため）。

### プロンプト（`prompt.js`）

voice-translator の `lib/buildPrompt.js` を土台に、翻訳を外してObsidian向け整形にする。
システムプロンプトの要点:

- 入力は整形外科医が自分用のアイデアメモを音声入力した文字起こしである。
- 医学用語・疾患名・薬剤名・解剖用語が似た音の一般語に誤変換されている可能性がある。文脈から妥当な医療用語に補正する。
- **ユーザー辞書**（`誤認識 → 正`、または正しい語の一覧）を優先して適用する。
- フィラー・言い直し・重複を除去し、意味は変えずに自然な書き言葉にする。内容の追加・推測による補足はしない。
- 内容が複数の論点を含む場合のみ、末尾に要点の箇条書きを付ける。短ければ付けない。
- タイトル（20字程度）とタグ（1〜3個）を付ける。タグは**タグ候補リスト**にあれば優先して使う。
- 出力形式（厳守、前後の説明なし）:

```
TITLE: タイトル
TAGS: タグ1, タグ2
---
本文（Markdown。見出し#は付けない）
```

ユーザーメッセージは原文のみ。

### 出力の解析とノート組み立て（`note.js`）

- 解析: 先頭の `TITLE:` 行と `TAGS:` 行、`---` 以降を本文とする。ストリーミング途中の不完全な状態でも例外を出さず、取れた分だけ返す。
  形式が崩れていた場合は、タイトルを原文の先頭20字、タグなし、全文を本文とみなす。
- 組み立て結果:

```markdown
---
created: 2026-10-02T14:30
tags: [voice-memo, タグ1, タグ2]
source: 音声メモ
---
# タイトル

本文

> [!note]- 元の音声テキスト
> 原文（改行ごとに "> " を付ける）
```

- `created` は端末時刻（ローカル時刻、分まで）。`voice-memo` タグは常に付与。
- タグは空白を `_` に置換し、`#` を除去する。

## Obsidian 連携（`obsidian.js`）

- URL: `obsidian://new?vault=<保管庫名>&file=<フォルダ>/<ファイル名>&content=<本文>`（各値は `encodeURIComponent`）。
- ファイル名: `YYYY-MM-DD タイトル`。`\ / : * ? " < > | # ^ [ ]` は除去、前後の空白とピリオドを除去、最大60文字。
- URL全体が 8,000 文字を超える場合: ノートをクリップボードにコピーし、`content` の代わりに `clipboard=true` を付けたURLで起動する
  （Obsidian URIの `clipboard` パラメータ）。
- 同名ファイルがある場合の挙動はObsidian側に任せる（実機で確認し、HANDOFFに記録）。
- 「コピー」ボタン: 組み立てたノート全文をクリップボードへ。

## 設定（`settings.js`、localStorage）

| 項目 | 既定値 |
|---|---|
| APIキー | 空（未設定なら整形せず、設定画面へ誘導） |
| モデル | `claude-opus-5-5` |
| 保管庫名 | `forest` |
| 保存フォルダ | `00_Inbox` |
| ユーザー辞書 | 空（1行1件。`誤 → 正` または正しい語のみ） |
| タグ候補 | 空（カンマ区切り） |

設定のエクスポート／インポート（APIキーを除くJSON）を付ける。機種変更・再インストール時のため。

## エラー処理

| 状況 | 動作 |
|---|---|
| マイク権限拒否 / 非対応ブラウザ | メッセージ表示。原文欄に手入力（またはキーボード音声入力）すれば整形は動く |
| ネットワーク・APIエラー（401/429/5xx等） | 原文はそのまま保持し、エラー内容と「再整形」ボタンを表示。401はAPIキー確認を促す |
| 中断（新しい確定による） | 正常動作として扱い、表示しない |
| 音声認識の自動停止 | 🎤ボタンを待機状態に戻す。再度押すと追記 |
| Obsidian未インストール | URLが開けない旨を表示し、「コピー」を案内 |

## テスト

- 単体テスト（`node --test`、外部依存なし）:
  - `prompt.js`: 辞書・タグ候補の差し込み、空の場合の扱い。
  - `note.js`: 正常な出力の解析、ストリーミング途中の不完全出力、形式崩れ時のフォールバック、frontmatter・callout組み立て。
  - `obsidian.js`: ファイル名サニタイズ、URLエンコード、長さ超過時の `clipboard=true` 切替。
- 手動確認（Android実機、Chrome）: 認識→リアルタイム整形→手動編集→Obsidian作成の一連の流れ、
  医療用語サンプル文での補正確認、ホーム画面追加後の起動。手順はHANDOFF.mdに記載する。

## スコープ外（YAGNI）

- iPhone対応、複数ユーザー、サーバー、録音ファイルの保存、外部文字起こしAPI、
  長時間口述、個人情報マスキング、メモ履歴の管理（保存先はObsidianのみ）。

## 費用の目安

1回の整形 ≒ 入力2,000トークン＋出力500トークン。Opus 5.5で約3円、1メモで数回走るため10〜15円程度。
Sonnet 5.5ならその約半分。
